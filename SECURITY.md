# Security policy

*Español más abajo: [Política de seguridad](#política-de-seguridad).*

## Reporting a vulnerability

If you find a security problem in this repository or in the hosted BORME API
services (`bormeapi.com`, `api.bormeapi.com`, `mcp.bormeapi.com`), please report
it privately:

- through GitHub, using the **Report a vulnerability** button on the
  [Security tab](https://github.com/bormeapi/borme-mcp/security) of this
  repository, or
- by email to `security@bormeapi.com`.

Please do not open a public issue for it.

A useful report says what is affected, how to reproduce it and what an attacker
could do with it. Please do not include personal data in it.

This document does not authorize security testing of production systems: do not
access other people's accounts, API keys or data, do not change or delete data
that is not yours, do not destroy or degrade any data, and do not run
denial-of-service tests or send traffic that degrades the service for others. If
you come across someone else's data, stop, do not keep it, and tell us.

## Version

Please report security problems against the latest commit on `main`.

## Política de seguridad

### Cómo informar de una vulnerabilidad

Si encuentra un problema de seguridad en este repositorio o en los servicios
alojados de BORME API (`bormeapi.com`, `api.bormeapi.com`, `mcp.bormeapi.com`),
le rogamos que nos lo comunique de forma privada:

- a través de GitHub, mediante el botón **Report a vulnerability** de la
  [pestaña Security](https://github.com/bormeapi/borme-mcp/security) de este
  repositorio, o
- por correo electrónico a `security@bormeapi.com`.

Le rogamos que no abra una incidencia (issue) pública para comunicarlo.

Un informe útil indica qué se ve afectado, cómo reproducirlo y qué podría hacer
un atacante con ello. Le rogamos que no incluya datos personales en él.

Este documento no autoriza realizar pruebas de seguridad en los sistemas de
producción: no acceda a cuentas, claves de API ni datos de otras personas, no
modifique ni elimine datos que no sean suyos, no destruya ni degrade ningún dato
y no haga pruebas de denegación de servicio ni envíe tráfico que degrade el
servicio para otros usuarios. Si encuentra datos de otra persona, deténgase, no
los conserve y comuníquenoslo.

### Versión

Le rogamos que comunique los problemas de seguridad tomando como referencia el
último commit de la rama `main`.
